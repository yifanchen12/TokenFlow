## 本轮行为

- 明确数字/JSON 任务使用独立参考，模型输入只有原任务、完整原文、解析提示和计算语义标志，不包含候选或规划答案。程序比较完整结果。
- 严格 JSON 拒绝重复键、非有限数和过深嵌套；字段路径和有界算式须绑定参考数值字段。引文必须存在。代码、近似和取整语义不套用有理数证明。
- 语义分歧保留原答案和未采用建议；不再自动调用模型改写。仅明确保值的数字包装或完整 JSON 围栏可本地整理，随后仍要复核。
- 界面区分当前答案与建议，复制净答案与当前选择一致。模型独立一致、引文存在和局部计算一致性都不证明整体业务语义正确。
