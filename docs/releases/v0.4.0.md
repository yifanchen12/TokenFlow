# TokenFlow v0.4.0

This release adds measurable prompt-quality checks, Chinese retrieval improvements and explicit OmniRoute model controls without changing users' global Harness settings.

## Changes

- Task-aware extraction keeps complete Python functions, Markdown sections or prose paragraphs. It retains the original input when bounded extraction is unsuitable or does not reduce the selected prompt.
- Evaluation supports relative repository sources, exact-answer scoring, provider-reported usage, source hashes, paired answers, incremental reports and enforceable quality gates.
- Chinese retrieval uses character bigrams/trigrams. Existing stored vectors are rebuilt transactionally and idempotently, preserving documents; status requests remain read-only. Search retains only top-k result memory while still scanning the corpus.
- OmniRoute requires an explicit model ID across chat, evaluation and Codex execution. Optional exact-ID allow-lists and a non-executing UI preview show the gateway and model, with upstream routing and cost clearly marked as gateway-managed/unknown.
- Updated separate English/Chinese documentation and security policies; Windows CI checks, builds and smoke-tests the EXE.

## Verification

Local Python and JavaScript syntax checks, application/evaluation self-checks, 60-case offline fact-retention checks and EXE startup/shutdown smoke checks passed. Smoke checks also cover model rejection, preview, Key non-disclosure, read-only store status and updated UI.

The final same-model run completed 60 repository QA pairs: both raw and selected prompts scored 60/60, all annotated facts were retained, and Ollama-reported input tokens fell from 184,031 to 135,866 (26.17%). This is a curated repository baseline, not proof of representative production quality or monetary savings.

See the [English report](https://github.com/yifanchen12/TokenFlow/blob/v0.4.0/docs/reports/repository-quality.md), [中文报告](https://github.com/yifanchen12/TokenFlow/blob/v0.4.0/docs/reports/repository-quality.zh-CN.md) and [per-case JSON](https://github.com/yifanchen12/TokenFlow/blob/v0.4.0/docs/reports/repository-quality.json) for the method, settings and limitations.

## Windows download

Download `TokenFlow.exe` and `SHA256SUMS.txt` from this release. No Python installation is required to start the EXE; external gateways, models and Harnesses remain separately installed/configured dependencies. Verify the EXE with `Get-FileHash ./TokenFlow.exe -Algorithm SHA256` and compare it with `SHA256SUMS.txt` before running.

The application binds to loopback by default. Model preview does not submit a task or predict an OmniRoute combo's final provider. A local gateway can still forward content to remote or paid services. Review the security policy before enabling integrations.
