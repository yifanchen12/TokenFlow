# 连接配置与模型刷新

1. 在 `model_providers.py` 约束 OmniRoute 密钥复用。相同地址可留空保留密钥，修改地址时采用新填的密钥，远程网关缺少密钥则拒绝保存。连接设置面板同步说明。
2. 两类模型客户端共用已有的禁止重定向策略，避免把模型输入或认证信息转发到其他服务。通过本机模拟 HTTP 服务验证接收请求的地址。
3. 在 `runtime_config.py` 中用比较后更新写回模型发现结果。请求进行期间用户编辑或重新配置连接时，保留新记录。以交错操作验证，沿用当前数据库结构。
4. 运行提供商测试和项目自检，用独立临时配置导入北邮 API，发现模型并执行可独立判分的合成任务。只登记北邮连接，禁用原生执行器，检查实际调用记录。

实测发现两道简单合计题均额外调用了规划器。在 `task_orchestrator.py` 的预检与执行共用规则中识别简单数量问句，继续独立验收，覆盖带筛选、换算和分步要求的反例，再以原题对照调用数及结果。

在任务执行中把已计算的原文统计传给预检，独立预览仍自行计算。在完整任务测试中计数，验证普通文本只统计一次。
